# Davide Zamboni - Personal Website

A minimal personal website built with Next.js 14 and TypeScript.

## Quick Start

```bash
# Run locally
./run.sh
```

Or manually:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Build & Deploy

```bash
# Build static site
npm run build

# Deploy to GitHub Pages (automatic on push to main)
```

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- CSS Modules
- GitHub Pages
